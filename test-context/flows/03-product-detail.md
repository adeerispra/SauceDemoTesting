# 03 — Product Detail Page

**URL:** `https://www.saucedemo.com/inventory-item.html?id=<product_id>`

← [Back to Index](../../README.md)

---

## UI Elements

| Element | Description |
|---|---|
| Back to Products button | Returns to the product listing page |
| Product image | Large image of the selected product |
| Product name | Full product name |
| Product description | Detailed description of the product |
| Price | Product price in USD |
| Add to Cart / Remove button | Toggles based on current cart state |
| Cart icon | Top-right, with badge showing cart item count |
| Hamburger menu icon (☰) | Top-left; opens the side navigation drawer |

---

## Notes

- The **Add to Cart** button becomes a **Remove** button once the item is added to the cart, and vice versa.
- Navigating back using the **Back to Products** button preserves any previously applied sort order on the listing page.
- See [Products Catalog](./08-products-catalog.md) for all available products.
