← [Back to Index](../../README.md)

---

## UI Elements

| Element | Description |
|---|---|
| Page title | "Products" |
| Hamburger menu icon (☰) | Top-left; opens the side navigation drawer |
| Cart icon | Top-right; shows a badge with the number of items in the cart |
| Sort dropdown | Filters/sorts the product grid |
| Product cards | Grid of all 6 available products |

---

## Product Card Elements

Each product card on the listing page contains:

- **Product image** — clickable, navigates to the product detail page
- **Product name** — clickable, navigates to the product detail page
- **Short description** — brief summary of the product
- **Price** — displayed in USD
- **Add to Cart button** — changes to a **Remove** button after the item is added to the cart

---
